# Time Since

A desklet that shows how long it has been since a date and time — or how long until one — in days, hours and minutes (seconds optional).

It sets no colors of its own, so it picks up your Cinnamon theme's text and desklet background and changes when you switch themes.

## Usage

1. Right-click the desktop → **Add Desklets**, add **Time Since**.
2. Right-click the desklet → **Configure…**
3. Set the date, time and an optional title.

Add as many instances as you like, each with its own date.

## Options

- **Title** – optional label above the counter
- **Date / Time** – the moment to count from (past) or to (future)
- **Show seconds** – tick every second instead of every minute
- **Show the "since …" line** – the target date under the counter
- **Size** – scale the whole desklet
